                  Settings /

                  Friends outside the house

                  Let friends who don't live here join the servers you choose. Only players on a server's allowlist can get in, and their Xbox sign-in is always checked. Everything else stays private.

                  Outside access

                  A hostname from your own domain or a dynamic DNS service (like DuckDNS) keeps working when your internet address changes. With a fixed address, the IP works too.

                    Your router

                    This needs UPnP turned on in the router. Without it, add the forwards below in the router's settings (often under "Port forwarding" or "Virtual servers"). Never forward port 8443: that's this panel, and it should stay inside the house.

                    Friends on Xbox, PlayStation and Switch

                    Consoles can't type a server address, so a friend changes their console's DNS to this home's address, joins a featured server such as The Hive, and lands in the list of servers open to them. This forwards the server list (19132, and 19300-19319 for newer Minecraft) and DNS (53) as well. The panel only answers the featured-server names for them; their console gets everything else from its second DNS. It works on most consoles; if one can't get online that way, the invite also explains a public alternative.

                      Settings /

                      Overnight updates and restarts

                      Each night, starting at the time below, the panel looks after the servers for three hours. It only touches a server nobody is playing on; one with players is tried again every minute until the three hours are up, then the next night.

                      Each is backed up first, and started again if it was running. Friends' games update themselves, and can't join a server that's behind, so this keeps everyone playing. Servers set to keep their version, and preview servers, are skipped.

                      A fresh start clears out slowdowns from long uptimes. A server that was updated that night isn't restarted again.

                                        Plugins
                                        
          
                                        Plugins add things to a Java server: land claims, homes and teleports, maps, mini-games. Changes apply when the server next starts. Each plugin keeps its settings in its own folder in plugins/.
                                        
          
                                          
        
                                          

        
                                          
          
                                          Find plugins
                                          
          
                                          From Hangar (PaperMC's plugin site) and Modrinth, made for Minecraft . The panel installs the newest release for that version, and any plugins it needs, and checks each download. Plugins run their own code on your server, so stick to well-known ones.
                                          
          
                                          
            
            
          
                                          
          
                                          
          
                                            
        
                                            
        
                                            Only the owner adds, updates and removes plugins, because they run their own code on the computer. You can turn installed ones off and on.
